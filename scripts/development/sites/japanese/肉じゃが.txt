# 母の肉じゃが

母は計量をしない人だった。それでも何度も作ってもらううちに、だいたいの分量がわかってきたので、書きとめておく。

## 材料（２人分）

| 材料 | 分量 |
|------|------|
| じゃがいも | ３個 |
| 牛こま切れ肉 | １５０ｇ |
| 玉ねぎ | １個 |
| にんじん | 半分 |
| しょうゆ | 大さじ２ |
| みりん | 大さじ２ |
| 砂糖 | 大さじ１ |

## 作りかた

1. じゃがいもは大きめに切って、水にさらす。
2. 鍋に油をひき、肉と玉ねぎを炒める。
3. じゃがいもとにんじんを加え、ひたひたの水と調味料を入れる。
4. 落としぶたをして、中火で２０分ほど煮る。

> 煮物は、火を止めてから味がしみる。

一晩おいた翌日のほうが、ずっとおいしい。
