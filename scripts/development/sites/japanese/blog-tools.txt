# このブログの書きかた

文章は、すべてパソコンのフォルダにテキストファイルとして保存している。エディタは Visual Studio Code 1.90 のこともあれば、iPhone 15 Pro の「メモ」アプリのこともある。フォルダは Blot と同期されて、数秒後には https://example.com/blog に反映される。

日本語と英語がまざった文章で、気をつけていること。

- 製品名（例：MacBook Air M2）は半角英数字で書く。
- 年号は「２０２４年」と全角でも「2024年」と半角でも読めるが、一つの文章のなかでは統一する。
- URL の `https://blot.im/how` は、そのままコピーして貼る。
- 速度は 120 WPM（１分あたり１２０語）くらい。

文字数を数える小さなスクリプトも、よく使う。

```js
const fs = require("fs");

const text = fs.readFileSync("post.txt", "utf8");
const count = [...text.replace(/\s/g, "")].length;

console.log(`文字数：${count}`);
```

コードのなかに日本語があっても、等幅フォントの幅がそろっているかどうかを確かめたくなる。「あいう」と "abc" が、きちんと２対１の幅で並ぶだろうか。テーマを作る人には、いつもそこを見てほしい。
