# Mathematics and code

I like to keep a formula next to a function. One is a claim about a surface; the other is just a way to count.

$$
\theta ;\ \mapsto \; \frac{1}{N} \sum_{i=1}^N \left| y_i - \mu_{\theta}(x_i) \right|^2 + \log[ \,  \sigma^2_{\theta}(x_i) \, ].
$$

Here is the same idea as a loop, which is easier to read and harder to trust:

```python
def fib(n):
    a, b = 0, 1
    for i in range(n):
        a, b = b, a + b
    return a
```
