CotEditor

Write your posts with CotEditor

CotEditor is a lightweight, open-source plain-text editor made for macOS. It launches quickly and includes syntax highlighting, powerful find and replace, automatic backups and a split editor.

How to use CotEditor with Blot

  1. Create a site and choose how to sync your folder with Blot.
  2. Open the synced folder in CotEditor and create a new Markdown file with a .md extension.
  3. Write your post, using Markdown for headings, links, lists and other formatting.
  4. Save the file. Blot will publish it automatically after the folder syncs.

CotEditor can also edit HTML directly, which is useful when you need more control over a post’s markup.
