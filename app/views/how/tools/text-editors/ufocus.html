uFocus

Write your posts with uFocus

uFocus is a distraction-free writing app for Mac, iPad, iPhone and Apple Vision. It works with plain-text files, including Markdown, and keeps the writing environment quiet so you can focus on your draft.

How to use uFocus with Blot

  1. Create a site and choose how to sync your folder with Blot.
  2. Link the synced folder as a library in uFocus, then create a Markdown file for your post.
  3. Write and save your post. Blot will publish the file automatically after the folder syncs.

uFocus includes a live outline for Markdown documents, several themes and optional focus modes such as highlighting the sentence or paragraph you are currently writing.
