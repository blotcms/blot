The Archive

Write your posts with The Archive

The Archive is a calm note-taking and writing app built around plain-text files. It supports Markdown, fast search, tags, links, saved searches and a focused writing interface.

How to use The Archive with Blot

  1. Create a site and choose a sync method for your folder, such as Dropbox or iCloud.
  2. Open the synced folder as a library in The Archive.
  3. Create or edit a note and save the notes you want to publish as Markdown files with a .md extension.
  4. Blot will publish the Markdown files from the synced folder as posts.

Because your notes remain plain text, you can keep using them in other editors or services if you ever change tools.
