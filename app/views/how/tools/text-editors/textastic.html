Textastic

Write your posts with Textastic

Textastic is a fast text and code editor for iPad, iPhone and Mac. It offers syntax highlighting for Markdown, HTML and many other file types, as well as remote file transfer and SSH support.

How to use Textastic with Blot

  1. Create a site and choose how to sync your folder with Blot.
  2. Open the synced folder in Textastic. On iPad or iPhone, Textastic can work with a Dropbox folder; on Mac, you can open the folder directly.
  3. Create or open a Markdown file with a .md extension and write your post.
  4. Save the file. Blot will publish it automatically after the folder syncs.

Textastic also supports HTML, so you can edit an HTML post directly when you need more control over its markup.
