Images

File extensions: .png .jpeg .gif .tiff .webp .avif .heic .heif

Put images directly into your site's folder and Blot will publish them as posts. If you prefer to keep image files in your folder without publishing them as posts, you can turn this off on the Images page in your dashboard.

Images in formats not widely supported on the web, such as TIFF, WebP, and AVIF, are automatically converted into PNG assets when published; the source file in your folder is not modified.

Compression

Blot does not compress your original image files or reduce their dimensions. Thumbnails are separate, resized images generated for templates; they do not replace the original file.

Thumbnails

When an image meets the thumbnail requirements, Blot generates thumbnails for an image post so you can show smaller images on an index page, archive, gallery, or social preview without loading the full image. A standalone image post uses its image as the source for these thumbnails. For other kinds of posts, Blot chooses the first suitable image in the post unless you set Thumbnail metadata. See the full thumbnail guide for the selection rules and how to override the choice.

Ignore a file

You can prevent a file from becoming a post or page if you start its name with an underscore. This is useful if you want to embed an image in a Markdown post.

Captioning an image

Blot uses the image's filename, without its extension, to generate both the caption and the alt text for the image. If the filename ends with @2x, Blot adds the necessary retina markup to reference the higher-resolution asset automatically.

Change the date of an image post

You can use the image's file name or its path to set its date.

EXIF

By default, Blot extracts selected EXIF metadata from image files that become posts. Your template can display this data if needed. You can change this setting on the Images page in your dashboard.

Mode EXIF data extracted
Basic (default) Make Model ExposureTime FNumber ISO FocalLength LensMake LensModel ImageDescription Flash
Full Basic fields plus location data: GPSPosition GPSLatitude GPSLongitude GPSAltitude
Off No metadata extracted

The images themselves which are served on your site always have their EXIF removed regardless of this setting.
