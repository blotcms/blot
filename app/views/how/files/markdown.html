Markdown

File extensions: .txt .md .rtf .textbundle

Markdown is a text-to-HTML conversion tool for web writers. Markdown allows you to write using an easy-to-read, easy-to-write plain text format that is simple to convert to HTML. Blot also supports math via the KaTeX plugin (rendered after conversion when enabled) and provides syntax highlighting for code snippets.

# Formatting

You can use *Markdown*, a lightweight markup language for plain text files.

Use it for links, headings, lists and much more.

Bold and italics

Surrounding text with two asterisks makes text bold:

**This text will be bold.**

To create italics, use a single asterisk (*) on either side of the text:

*This text will be italic.*

Both * or _ symbols work to make text bold or italic. This way you can combine bold and italic in the same sentence. For example:

**Everyone _must_ listen.**

Headings

You can create headings using the octothorpe (#).

# Largest heading

Use two octothorpes to create a subheading.

## Subheading

Alternatively, for H1 and H2, an underline-ish style:

Alternative heading
===================

Alternative subheading
----------------------

Links

Create a text link by wrapping the linked text in brackets ([ ]) and the URL in parentheses (( )). For example:

[Wikipedia](https://wikipedia.org)

A relative link, e.g. [Report](report.pdf), is resolved based on the location of the file you're writing in, not your post's URL.

Images

Use the syntax for a link, with an exclamation point (!) in front. For example: 

![Image title](https://url.of/the/image.jpg)

If the file _image.jpg is inside the same directory, then you can use a relative path like so:

![Image title](_image.jpg)

Otherwise, use an absolute path with your site folder as root:

![Image title](/_Files/image.jpg)

You can wrap the image in a link like so:

[![Image title](https://url.of/the/image.jpg)](https://url.of/the/page)

Lists

Make a bulleted list by starting each item with a hyphen (-) or an asterisk (*). Add a space after the marker.

- Round
- Shell
- Projectile

Create a numbered list by preceding list items with a number.

1. Eins
2. Deux
3. Tres

Create a list that starts with a custom number like this:

 9) Ninth
10) Tenth
11) Eleventh

Create a list with non-digit markers like this:

i. Unus
ii. Duo
iii. Tres

If it is a capital letter, use two spaces after the period:

A.  Unus
B.  Duo
C.  Tres

Create a checklist like so:

- [x] First task
- [ ] Second task
- [ ] Third task

Footnotes

Use square brackets and a caret (^) to mark the position of a footnote in your text:

Use this syntax.[^1] Another line with a different footnote.[^2]

And then write the footnotes themselves at the bottom of your file like this:

[^1]: And the note goes here.
[^2]: And the second goes here too.

You can also write footnotes inline with your text:

Use this syntax ^[Footnote text goes here] for inline footnotes.

Strike out text

Put a double tilde (~) on either side of the text you want to strikethrough:

~~Strike out mistakes~~

Highlighting

Surround text with double equals signs (==) to mark or highlight it:

==This text will be highlighted.==

Code

Indent code with four spaces:


    var foo = “bar”;

You can also wrap code with three backticks (`) and specify the language to enable syntax highlighting:

```javascript
var foo = "bar";
```

You can customize your code's syntax highlighting by modifying the highlight.js CSS file which comes with your site's template.

Horizontal rules

Use three or more hyphens (-), asterisks (*) or underscores (_) to create a horizontal rule.

---
***
___

Blockquotes

Markdown uses email-style > characters for block quoting. They are presented as:

> This is a blockquote with two paragraphs.
>
> This is the second paragraph. Vestibulum enim wisi.

Callouts

Start a blockquote with [!info] to create a callout:

> [!info] Here's a callout title
> Here's a callout block. It supports **Markdown**, etc.
Here’s a callout title

Here’s a callout block. It supports Markdown, etc.

Use + or - to make the callout collapsible (initially expanded or collapsed, respectively):

> [!info]- Here's a collapsible callout
> Here's the collapsible content.
Here’s a collapsible callout

Here’s the initially-collapsed content.

Supported callout types are note, abstract, info, todo, tip, success, question, warning, failure, danger, bug, example, and quote. The syntax is based on Obsidian callouts. You can customize the appearance of callouts in your template.

Tables

You can use the following syntax to create tables:

| Syntax      | Description |
| ----------- | ----------- |
| Header      | Title       |
| Paragraph   | Text        |

HTML

You can mix HTML tags directly into Markdown files when you need behavior beyond Markdown.

Citations

You can use an external BibTex citations file to store your citations. Read the guide to using citations.

Wikilink embeds

Blot supports Obsidian-style wikilink embeds using the ![[...]] syntax. You can embed media and also embed Markdown/text notes directly into another note.

![[Notes/Overview.md]]
![[Notes/Todo.txt]]
![[Notes/Appendix.markdown]]

Embedded note files are rendered inline as Markdown. For full details on lookup rules, embedding by relative and absolute path, and supported file types, see the Wikilinks guide.

TextBundle

You can use the TextBundle format to embed images in Markdown files when using supported apps including Ulysses and Bear.

Divs and spans (Pandoc)

Blot supports Pandoc's native Div and Span syntax in Markdown, so you can add attributes with fenced divs and bracketed spans. This makes it possible to create custom features in your template by targeting classes and IDs in your CSS or layout. See the developer documentation for more on customizing templates.
