Folder posts

Files inside a folder whose name ends in + become a single post instead of separate posts. For example, files inside a folder called Essay + are joined into one post. 

Essay +
  Introduction.md
  Part one.md
  Part two.md
  diagram.png
Posts

This is useful when a single post is easier to write as several files — a long essay split into chapters, a photo story with captions between the images, or a page that keeps its images and text side by side in the folder.

Create a folder post

Make a folder and add a + to the end of its name. Put files that Blot can publish inside. An empty + folder is ignored until you add a supported file.

The order of the files

Files are joined alphabetically by name. Prefix them with numbers to control the order. Blot includes sub-folders in the same list, sorting by sub-folder name and then file name:

01 Introduction.md
02 Photos › 01 Street.jpg
02 Photos › 02 Museum.jpg
03 Conclusion.md

Folder posts can include supported files in sub-folders, up to 50 files total. Posts with more than 50 files are not published.

Ignore a file

To ignore one file in a folder post, start its name with an underscore. For example, _notes.md stays in the folder but is left out of the post.

The title

If none of the files inside the folder has a heading, Blot adds one for you using the folder’s name. Add a heading or Title metadata to one of the files to set the title yourself.

Drafts

Folder posts work inside a Drafts folder. A folder such as Drafts/Essay + creates a single draft preview and keeps it up to date as you edit the files.

Edit or remove a folder post

Add, edit, rename, or delete files inside the folder to update the post. Blot rebuilds it whenever any file inside changes. Delete the folder to remove the post.

Building a custom layout

Blot wraps a folder post in HTML that marks where each file begins, so a template can lay the files out as a slideshow, a gallery, or another custom design. See Folder posts in the developer guides for the markup and examples.
