Folder posts

Add a + to the end of a folder’s name to publish everything inside it as a single post. When Blot sees a folder such as Essay +, it joins every file inside into one entry and publishes it at /essay.

  Part two.md
  diagram.png
Posts

This is useful when a single post is easier to write as several files — a long essay split into chapters, a photo story with captions between the images, or a page that keeps its images and text side by side in the folder.

Create a folder post

Make a folder and add a + to the end of its name. Put your files inside. Blot publishes the post at the folder’s path without the +, so Essay + becomes /essay.

Only folders that contain a file Blot can publish become posts. An empty + folder is ignored until you add a supported file.

The order of the files

Files are joined in alphabetical order by file name. To control the order, name the files so they sort the way you want, for example 01 Introduction.md, 02 Part one.md, 03 Part two.md.

A + folder can contain sub-folders. Blot looks through them too, up to a total of 50 files. If a folder post would contain more than 50 files, Blot does not publish it.

The title

If none of the files inside the folder has a heading, Blot adds one for you using the folder’s name. Add a heading or Title metadata to one of the files to set the title yourself.

Drafts

Folder posts work inside a Drafts folder. A folder such as Drafts/Essay + creates a single draft preview at /drafts/essay and keeps it up to date as you edit the files.

Edit or remove a folder post

Add, edit, rename, or delete files inside the folder to update the post. Blot rebuilds it whenever any file inside changes. Delete the folder to remove the post.

Building a custom layout

Blot wraps a folder post in HTML that marks where each file begins, so a template can lay the files out as a slideshow, a gallery, or another custom design. See Folder posts in the developer guides for the markup and examples.
