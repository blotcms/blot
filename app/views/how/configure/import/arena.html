Are.na

You can import a public Are.na channel using Blot’s Import from Are.na tool on the dashboard.

Run the importer

On your dashboard, open Import from Are.na and paste a public channel URL. When the import finishes, download the ZIP archive, extract it, and place the files in your site’s folder.

What Blot imports

The importer turns channel items into files in a ZIP archive. Image blocks are downloaded and stored with the rest of the export. Link blocks become bookmark files. Text and other content is written as files you can keep in your site’s folder alongside Markdown and images. Publication dates from the channel are preserved in the filenames.
