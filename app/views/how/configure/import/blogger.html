Blogger

You can import a Blogger blog by downloading a content backup from Blogger, then using Blot’s Import from Blogger tool on the dashboard.

Export your blog

In Blogger, open Settings, scroll to Manage blog, choose Back up content, then select Download to get an .atom export file.

Run the importer

On your dashboard, open Import from Blogger and upload the Atom export. You can optionally enter your site’s URL so same-site links are rewritten as root-relative paths. When the import finishes, download the ZIP archive, extract it, and place the files in your site’s folder.

What Blot imports

The importer converts published posts and pages into Markdown files. It downloads images and linked PDF files alongside the Markdown. Original post URLs and publication dates are preserved.
