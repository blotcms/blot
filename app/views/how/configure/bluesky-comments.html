Bluesky comments

Blot’s Bluesky comments plugin shows the replies to a Bluesky post at the end of an entry. Blot looks for the Bluesky post that links to the page and renders its thread as a comment section, following the approach described in Emily Liu’s write-up.

  1. Open the Services page and enable Bluesky comments.
  2. Enter your Bluesky profile URL (for example https://bsky.app/profile/example.bsky.social). Blot uses this to find the post you made linking to each page.
  3. Publish a post on Bluesky that links to the entry’s URL. Once it is live, the replies appear beneath the entry. Until then, nothing is shown.

Pinning a specific thread

To attach a particular Bluesky post to an entry instead of relying on the automatic lookup, add a Bluesky field to the entry’s metadata set to the post’s URL or AT URI, for example: 

Bluesky: https://bsky.app/profile/example.bsky.social/post/3k7abcde2fg2h

Comments follow the usual rules: they are shown on posts and hidden on pages unless you set Comments: Yes in the page’s metadata, and any entry with Comments: No hides them. You can switch between comment systems at any time from the Services page.
